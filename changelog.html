V14.3 · nouveau24/08/2026 · 18:30 (UTC+2)

🔐 Connexion des comptes normaux corrigée

  • Correction de la redirection OAuth : un compte normal revient maintenant sur le site principal au lieu d'être envoyé vers le panneau administrateur.
  • Un utilisateur non administrateur peut se connecter avec son propre compte Discord sans devoir être présent dans la liste des administrateurs.
  • Les données du profil restent liées au compte connecté.
  • Version de cache des scripts d'authentification augmentée pour éviter de conserver l'ancienne configuration.
V14.2 · vérifié23/08/2026 · 18:39 (UTC+2)

🌳 Catalogue étendu

  • Ajout de nouveaux bois et variantes pour augmenter la variété des blocs et objets.
  • Ajout d'icônes locales pour les principaux nouveaux objets.
  • Les bouteilles d'XP métier à 1000 XP sont conservées dans le catalogue.
  • Le portefeuille n'est plus dupliqué dans le Catalogue et reste accessible depuis le Budget.
  • L'animation du profil est bouclée avec un cycle court.
