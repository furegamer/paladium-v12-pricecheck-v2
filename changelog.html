📝 Historique public des améliorations

Changelog

Les changements affichés ici sont uniquement ceux qui ont été vérifiés dans le code du site. Une fonctionnalité incomplète n'est pas annoncée comme terminée.

V12.8 · vérifié

🧹 Quality Update & fiabilité

  • Version centrale du PriceCheck passée à V12.8 : le badge « nouvelle interface » se met à jour depuis une seule constante.
  • La priorité des images locales est conservée afin d'éviter qu'une ancienne image Supabase remplace une icône correcte du catalogue.
  • Les nouveaux items et créatures restent intégrés au catalogue avec leurs prix clairement présentés comme des estimations lorsqu'ils ne sont pas confirmés.
  • Le site conserve les contrôles de recherche, filtres, tri, favoris, marché et XP/POG existants.
SEO · vérifié

🔎 Préparation à l'indexation

  • robots.txt autorise l'exploration du site.
  • Une sitemap.xml liste les pages publiques importantes.
  • La structure SEO a été préparée pour aider les moteurs de recherche à comprendre le PriceCheck.
Déploiement · vérifié dans le code

🛡️ Contrôles avant mise en ligne

  • Le workflow de déploiement contrôle les fichiers indispensables du site.
  • Les références d'images sont contrôlées pour limiter les fichiers manquants ou invalides.
  • Les pages HTML importantes sont vérifiées avant publication.

V12.7 · vérifié

  • Ajout de nouveaux items et variantes : Findium, Voidstone, blocs de minerais, lingots et cristaux.

Correction · vérifié

🖼️ Priorité des images locales

Les données distantes Supabase ne remplacent plus automatiquement l'image locale du catalogue lorsqu'une correspondance locale est connue. Cela évite qu'une ancienne URL d'image enregistrée en base fasse apparaître une mauvaise icône.
