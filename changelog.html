Changelog

Les changements affichés ici sont uniquement ceux qui ont été vérifiés dans le code du site. Une fonctionnalité incomplète n'est pas annoncée comme terminée.

V12.8 · vérifié

🧹 Quality Update & fiabilité

  • Version centrale du PriceCheck passée à V12.8 : le badge « nouvelle interface » se met à jour depuis une seule constante.
  • La priorité des images locales est conservée afin d'éviter qu'une ancienne image Supabase remplace une icône correcte du catalogue.
  • Le catalogue étendu et les créatures restent intégrés avec les nouveaux éléments clairement présentés comme des estimations lorsqu'ils ne sont pas confirmés.
  • Recherche, filtres, tri, favoris, marché et XP/POG restent disponibles.
V12.8 · vérifié

🛡️ Contrôles de publication

  • Le workflow de déploiement contrôle les fichiers indispensables du site.
  • Les références d'images et les pages HTML importantes sont vérifiées avant publication.
  • Les fichiers image invalides peuvent désormais faire échouer le contrôle plutôt que de laisser passer une icône cassée.
V12.8 · vérifié

🔎 SEO & visibilité

  • Les métadonnées SEO et la structure du site sont préparées pour faciliter la découverte par les moteurs de recherche.
