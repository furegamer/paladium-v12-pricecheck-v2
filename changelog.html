V12.9 · vérifié22/08/2026 · 21:47 (UTC+2)

👤 Données du profil directement dans la barre du pseudo

  • La zone où le pseudo est affiché contient maintenant les informations principales du profil.
  • Affichage du solde P$, des PB et du niveau POG directement dans cette zone.
  • Les niveaux de Mineur, Fermier, Alchimiste et Chasseur sont également résumés à côté du pseudo.
  • La zone reste cliquable et ouvre directement la page Profil.
  • Les informations se rafraîchissent après une modification du portefeuille, des PB, du pseudo ou des niveaux.
  • Interface adaptée aux petits écrans pour éviter les superpositions.
V12.9 · vérifié22/08/2026 · 21:14 (UTC+2)

👤 Profil directement depuis le pseudo

  • Le pseudo affiché sur le site ouvre maintenant directement la page Profil.
  • Le bouton Profil séparé dans la navigation n'est plus recréé, afin d'éviter les doublons.
  • Le pseudo reste personnalisable et le lien continue de fonctionner après les mises à jour dynamiques de l'interface.
  • Le cache du script de profil a été actualisé pour que la correction soit bien chargée sur le site.
V12.9 · vérifié22/08/2026 · 18:05 (UTC+2)

🎁 Récompenses des métiers & POG

  • Ajout d’un sélecteur pour voir la récompense documentée de chaque niveau de métier.
  • Récompenses Mineur, Fermier, Chasseur et Alchimiste renseignées pour les niveaux 1 à 20 à partir des pages Java du wiki Paladium.
  • Chaque niveau sépare maintenant les gains (P$, Paladium, Trixium, ressources, etc.) des crafts débloqués.
  • Ajout d’un indicateur « à documenter » pour éviter d’inventer les récompenses des niveaux non détaillés dans la source.
  • La progression POG affiche maintenant les blocs OS disponibles et classe les blocs enregistrés par difficulté de casse.
  • Le bloc le plus facile du palier courant est mis en évidence.
V12.9 · vérifié22/08/2026 · 17:38 (UTC+2)

🛒 Budget & catalogue fiabilisés

  • Le clic sur le portefeuille ouvre maintenant directement la page Budget pour voir ce qui est achetable avec son solde.
  • Le catalogue local s'affiche immédiatement, même si la synchronisation distante prend du temps.
  • La synchronisation Supabase dispose d'un délai maximum afin d'éviter de bloquer l'affichage du catalogue.
  • Après une synchronisation réussie, le catalogue et le Market sont automatiquement rafraîchis.
  • Correction d'un conflit JavaScript entre les fonctions déjà présentes dans data.js et le nouveau code du catalogue.
